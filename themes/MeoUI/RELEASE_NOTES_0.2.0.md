# MeoUI 0.2.0

This release updates the MeoUI Showcase into a more complete UI kit demo and ships the typography/design-spec work as release assets.

## Highlights

- Comfortaa/Roboto typography system bundled into the QML module.
- Semantic `MeoText` typography for page titles, sections, body copy, and labels.
- Cleaner Showcase layout with narrower drawer, unified content width, and lighter top app bar.
- Expanded component states for buttons, inputs, data tables, chips, navigation previews, and layout patterns.
- New `DESIGN_SPEC.md` plus static `MeoUI-SpecSite`.

## Assets

- `meo-ui-showcase-windows-x64-0.2.0.zip`
  - Windows Showcase build with Qt runtime files.
- `meo-ui-showcase-linux-x64-source-0.2.0.tar.gz`
  - Linux source package with `run-showcase-linux.sh`; requires Qt 6 and CMake on Linux.
- `meo-ui-runtime-0.2.0.tar.gz`
  - QML runtime module, bundled fonts, and `install-runtime.sh`.
