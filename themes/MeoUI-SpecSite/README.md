# MeoUI Spec Site

Open `index.html` directly in a browser to view the MeoUI design specification site.

## Replacing Component Screenshots

Component images live in:

```text
assets/components/
```

Every component card uses a same-name PNG file, for example:

```text
assets/components/MeoButton.png
assets/components/MeoTextField.png
assets/components/MeoPageLayout.png
```

To replace a placeholder, take a screenshot and save it over the matching file name. Keep the file name unchanged so the site updates automatically.

Recommended screenshot size:

```text
1280 x 720 PNG
```
