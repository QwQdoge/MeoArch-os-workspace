Material Design 3 / Meo semantic tokens

MeoUI 设计规范

所有页面、组件、动效和图片替换入口集中在这里。页面代码必须表达设计意图，例如 title.big、motion.fast、state.hover，而不是散落的数字。

Core rule

核心原则

语义优先

页面里用 MeoText、MeoButton、MeoPageLayout，不要直接写字号、动画时长和颜色。

状态统一

hover、focus、press、drag 都走 MeoStateLayer，点击反馈使用圆形 ripple。

组件先行

新界面先查组件库；只有缺少组件时才新增组件，新增时必须补文档和图片占位。

Parameters

所有核心参数

Component catalog

全部组件和图片文件

每个组件都有一个占位图片。截图替换时保持同名文件即可，例如 assets/components/MeoButton.png。

Usage

如何使用

页面标题

MeoText {
    text: "Settings"
    typeRole: "title"
    typeSize: "big"
    emphasized: true
}

按钮

MeoButton {
    text: "Continue"
    icon.name: "arrow_forward"
    type: "filled"
    size: "m"
}

页面布局

MeoPageLayout {
    title: "Library"
    subtitle: "Manage installed packages."

    MeoCard {
        type: "filled"
    }
}

Compliance

必须遵守

  • 页面文字必须优先使用 MeoText，禁止在页面里写 font.pixelSize: 54 这类裸数值。
  • 动画时长必须使用 motionDurationFast、motionDurationMedium 等 token。
  • 按钮 hover、press、focus 必须走 MeoStateLayer，点击使用圆形 ripple。
  • 颜色必须使用角色色，例如 primary 搭配 contentOnPrimary。
  • 新增组件必须在本网页组件列表中增加条目，并创建同名图片占位。
